# Operation Eggshell

Landing page de aniversário do Nicolas — experiência interativa mobile-first.

## Desenvolvimento local

```bash
npm install
npm run dev
```

Abra: http://localhost:5173/operation-eggshell/

## Build

```bash
npm run build
npm run preview
```

## Deploy

Push para `main` dispara GitHub Actions e publica em:

https://sereiaroger.github.io/operation-eggshell/

## Stack

- Vite + Vanilla JavaScript
- GitHub Pages
